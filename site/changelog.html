changelog

what changed.

short notes, newest first. the app is 1.0.0.

1.0.0 current the dossier fills itself in

less typing, more finding.

  • auto thumbnails. add a live url or repo and napkin++ captures the site's social preview image. the project list has a thumbnail grid view.
  • auto-detect stack. from a live url and/or a github repo: hosting, database, auth, email, dns/registrar, languages and frameworks. everything arrives as a suggestion you tick and edit.
  • feedback and bug reports inside the app, without a separate support site.
  • update checks built in.
  • detection never silently overwrites a field you've already filled in.
0.2.0 previous the build that made it a real app

the dossier.

  • projects with aliases, tags, stack, status, folders and a favourite star.
  • accounts as a visible list, with typed fields — password, pin, api token, recovery code.
  • env vars per environment, pasted from a .env block or typed a row at a time.
  • notes and code with line numbers and brace/indentation folding.
  • links and services with one-click open and copy.
  • ⌘K search across everything, and ⌥Space quick capture from anywhere.
  • folders, merge, and import from an old text file.
  • light and dark, eight paper palettes, four accent presets, six dock colourways.
  • atomic writes, daily backups, session undo, and redacted markdown export.

still missing, plainly: encryption at rest, sync, sharing, totp, and attachments. they're on the list, not in 1.0. support explains how to nudge, and contact is the inbox.
